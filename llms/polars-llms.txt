# Polars

> Polars is a blazingly fast, open-source DataFrame library and query engine written in Rust, with first-party bindings for Python, Rust, Node.js, and R. It offers lazy and eager execution, streaming for larger-than-memory datasets, query optimization, multi-threading, and the Apache Arrow columnar format. Polars Cloud extends the same API to managed and on-premise distributed compute with zero code changes.
